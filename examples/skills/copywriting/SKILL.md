# Copywriting & Content

## KAPAN PAKAI

```
IF user minta nulis caption / artikel / email / landing page / thread / script → PAKAI
IF user minta edit/rewrite teks marketing → PAKAI
IF user minta coding / data analysis → JANGAN PAKAI
```

---

## PROCEDURE (ikuti exact)

### Step 1: Klarifikasi (WAJIB tanya kalau belum jelas)

```
TANYA: "Audience siapa?" (umur, interest, level awareness)
TANYA: "Goal apa?" (awareness / engagement / conversion / edukasi)
TANYA: "Platform mana?" (IG / X / email / blog / landing page)
TANYA: "Tone apa?" (formal / casual / lucu / serius)
TANYA: "CTA apa?" (beli / klik / subscribe / share)
```

```
IF user jawab semua → langsung tulis
IF user jawab sebagian → asumsi yang masuk akal, state asumsi
IF user gak jawab sama sekali → tanya lagi, jangan asumsi semua
```

### Step 2: Pilih format berdasarkan platform

```
IF platform = Instagram caption:
  - Hook: 1 kalimat pertama yang bikin stop scroll
  - Body: 3-5 kalimat value
  - CTA: 1 kalimat clear
  - Hashtag: 5-10 relevan
  - Max: 2200 karakter

IF platform = Thread X:
  - Tweet 1: hook + promise
  - Tweet 2-8: 1 poin per tweet, short sentences
  - Tweet terakhir: CTA + retweet request
  - Max per tweet: 280 karakter

IF platform = Email:
  - Subject: <50 karakter, curiosity/benefit
  - Preview text: extend subject
  - Body: problem → agitate → solve → CTA
  - CTA button: 1 saja, action verb
  - Max: 200 kata

IF platform = Landing page:
  - Hero: headline + subheadline + CTA
  - Social proof: testimonial / angka
  - Features → Benefits (bukan fitur doang)
  - FAQ: handle objections
  - Final CTA: repeat

IF platform = Artikel/blog:
  - Title: SEO + curiosity
  - Intro: hook 2-3 kalimat
  - Body: H2/H3 structure, scannable
  - Conclusion: summary + CTA
  - Word count: sesuai brief user

IF platform = Script video:
  - Hook: 3 detik pertama
  - Setup: 15-30 detik context
  - Value: main content
  - CTA: 10-15 detik closing
  - Format: [VISUAL] + [NARASI]
```

### Step 3: Tulis dengan rules ini

```
RULE: Specific > generic ("hemat 2 jam/hari" bukan "hemat waktu")
RULE: Benefit > feature ("tidur nyenyak" bukan "memory foam 10cm")
RULE: Active voice ("Download sekarang" bukan "Dapat di-download")
RULE: 1 CTA per piece (jangan banyak pilihan)
RULE: Hook kuat di kalimat pertama (bikin orang lanjut baca)

DO NOT: opener AI slop ("Di era digital...", "Dalam dunia yang serba cepat...")
DO NOT: filler tanpa value ("Perlu diketahui bahwa...")
DO NOT: generic tanpa personality ("Produk berkualitas tinggi...")
```

## CONTOH OUTPUT: Email Subject Lines (3 variasi)

```markdown
## Email Subject Lines: SaaS Free Trial Ending

**Audience**: Free trial users yang belum upgrade
**Goal**: Convert to paid
**Tone**: Friendly urgency

---

**Option A** (scarcity): "Trial lo habis besok — ini yang lo miss kalau stop"
**Option B** (benefit): "Tim lo udah hemat 14 jam minggu ini. Lanjutin?"
**Option C** (curiosity): "3 fitur yang belum lo coba (dan kenapa worth it)"

---

### Notes
- A = urgency-driven, cocok kalau user aktif
- B = value-driven, cocok kalau user already engaged
- C = curiosity-driven, cocok kalau user belum explore features
```

## DECISION TREE: Tone

```
IF audience = Gen Z → casual, slang OK, emoji OK
IF audience = professional/B2B → semi-formal, data-driven, no emoji overload
IF audience = parents/ortu → warm, relatable, bahasa sehari-hari
IF audience = mixed/unclear → default: friendly professional
```

## DECISION TREE: Length

```
IF IG caption → max 2200 char (tapi ideal 150-300)
IF Tweet → max 280 char
IF Email body → 150-200 kata
IF Blog → 800-2000 kata (tanya user)
IF Landing page → scannable, bukan wall of text
```

---

## VERIFICATION

```
□ Audience + goal jelas?
□ Tone konsisten dari awal sampai akhir?
□ CTA clear dan cuma 1?
□ Hook kuat (kalimat pertama bikin lanjut baca)?
□ Panjang sesuai platform?
□ Gak ada AI slop opener?

IF ada □ TIDAK → rewrite
```
