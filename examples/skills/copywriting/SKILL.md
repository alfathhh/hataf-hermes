# Copywriting & Content

Nulis konten with purpose. Dari caption IG sampe landing page copy.

## When to Use

- Caption IG/TikTok
- Artikel/blog
- Email marketing
- Landing page copy
- Thread X
- Script video
- Newsletter

## Procedure

### 1. Klarifikasi WAJIB

Audience? Goal? Platform? Tone? Panjang? CTA?

### 2. Format per platform

(IG caption, Thread X, Artikel, Email, Landing page, Script video — each with structure template)

## Rules

- Specific > generic
- Benefit > feature
- Active voice
- 1 CTA per piece
- NO AI slop opener ("Di era digital...")

## Pitfalls

1. Nulis tanpa tau audience
2. AI slop generic opening
3. Terlalu panjang untuk platform
4. CTA buried/unclear
5. Tone inconsistent

## Verification

1. Audience + goal jelas? 2. Tone konsisten? 3. CTA clear? 4. Hook kuat? 5. Panjang sesuai platform? 6. No AI slop?
